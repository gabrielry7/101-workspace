## Prueba privada de Pixabay

La clave se carga exclusivamente desde `.env` ignorado. [receipt.json](../evidence/corrections/b2/pixabay/receipt.json) conserva parámetros no sensibles, timestamps, estado HTTP, SHA/tamaño de respuesta y cabeceras de cuota; no conserva la URL autenticada ni la clave. Una búsqueda `red bell peppers`, `per_page=3`, sin paginar/reintentar/descargar. No se afirma haber inspeccionado esos píxeles ni que esos recursos tengan permiso para una web final.

El JSON crudo se movió antes de staging a `.tools/b2-pixabay-cache/response.json`, ignorado. No se publica en Git, no se reproduce ni se muestra como catálogo. Ventana privada de caché: 24 h desde el timestamp del recibo, hasta `2026-10-16T01:34:34.918Z`. No hay temporizador persistente: una vez vencida, ejecutar `scripts/b2-pixabay-request.ts --purge-expired-cache` elimina sólo ese archivo fijo sin contactar al proveedor. La receta rechaza repetir el recibo y no permite consumir una respuesta caducada; no se guarda como evidencia redistribuible ni se infiere permiso de archivo histórico de respuestas.

Siguiente paso audiovisual: seleccionar un archivo y necesidad explícitos bajo el flujo permitido, revisar ficha/licencia/terceros y permiso de inspección/procesamiento antes de adquirirlo. Una conexión para muchas webs necesitará una evaluación contractual/operativa propia; esta consulta no demuestra autorización de automatización a escala.
