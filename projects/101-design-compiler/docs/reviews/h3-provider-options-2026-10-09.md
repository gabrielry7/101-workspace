## Opciones y diferencias

| Proveedor | Medios y adquisición documentada | Límites relevantes | Evaluación pendiente |
|---|---|---|---|
| Pexels | Fotos/videos gratuitos descargables; API oficial existente, pero entrega de nuevas claves PAUSADA según captura del usuario y aviso oficial comprobado el 2026-10-09 | No disponible como conexión nueva sin clave autorizada. Enlace visible a Pexels en solicitudes API, crédito a fotógrafos cuando sea posible, límites; no replicar servicio. Licencia general sin atribución obligatoria no elimina condiciones API | Reapertura o acceso acordado, además de adecuación exacta de nuestra app y flujo, almacenamiento/retención, multicliente, terceros e IA. No se verificó funcionamiento de claves existentes |
| Pixabay | Imágenes/videos por API; biblioteca web también ofrece audio. La API consultada sólo documenta imágenes/videos; indica descargar imágenes al servidor para uso permanente | Caché de solicitudes 24 h, solicitudes humanas, sin muchas consultas automatizadas ni descarga masiva sistemática; key necesaria. No hotlink permanente de imágenes | Compatibilidad con generación autónoma 101 y volumen; adquisición de audio; multicliente, terceros y operaciones IA |
| Adobe Stock | Búsqueda, licencia, historial y descarga por API; imágenes/vectores/video | Autenticación, entitlement y licencia por activo; mismo recurso para distintos clientes requiere licencias separadas. Algunas ofertas CC Pro requieren habilitación comercial API específica | Contrato/plan exactos, costo/volumen, app autorizada, cliente/proyecto, editorial/terceros, IA, retención y caché |
| Unsplash | Fotos con descarga web permitida por su licencia; API con búsqueda | API exige hotlink desde URLs devueltas, atribución y notificación de evento de descarga. Alojar las imágenes de API en infraestructura propia requiere alternativa acordada | Acuerdo para archivo local y reproducción offline, uso exacto, terceros, IA, volumen |
| Artlist | Música/SFX/footage según suscripción; descarga manual, Pro/Business contempla proyectos de clientes | Prohíbe descargar mediante software/bots; assets integrados en proyectos, no compartir archivos sueltos. Publicar nuevos proyectos durante suscripción; Social no equivale a cobertura de clientes | Plan/acuerdo exacto, uso de audio en web frente a sincronización en video, derechos y operación IA concretos; automatización necesita acuerdo distinto |
| Wikimedia Commons | Archivos descargables según licencia de cada ficha; API MediaWiki disponible | Autor/licencia por archivo; condiciones como atribución y share-alike según licencia; archivos con copyright dudoso no deben usarse. No asumir que uploader sea autor | Adecuación/calidad por activo, terceros, volumen/acceso/retención y transformaciones concretas |

Gratis no equivale a irrestricto. API disponible no equivale a autorización para toda automatización, y documentación de descarga no prueba licencia del uso concreto. No se hizo benchmark visual comparativo ni inspección de nuevos recursos.

## Propuesta de evaluación posterior

La recomendación inicial de Pexels como primera conexión no comprobó el paso de emisión de credenciales y queda corregida: Pexels está pendiente para una conexión nueva por pausa oficial de claves. La documentación describe la API, pero eso no prueba disponibilidad de acceso. [Aviso oficial](https://help.pexels.com/hc/en-us/articles/900004904026-How-do-I-get-an-API-key) y [página API](https://www.pexels.com/api/) confirman la pausa; no se observó fecha de reapertura. Captura aportada por el usuario confirma el mensaje en Request API Access; no se copia el archivo temporal al repo.

Evaluar acceso real a candidatos alternativos antes de elegir: Adobe Stock para opción comercial con licenciamiento trazable, sujeto a presupuesto y aprobación del uso/API; Pixabay para selección puntual con participación humana, sin asumir búsquedas autónomas masivas; Wikimedia para archivos concretos. El usuario aportó una clave de Pixabay después de esta investigación: credencial disponible por declaración, autenticación/cuota/alcance aún NO PROBADOS. El secreto no se conserva en este archivo ni en el prompt final. No se verificó emisión de claves ni credenciales de las otras alternativas. Artlist queda como opción audiovisual manual o negociada. Unsplash requiere resolver alojamiento API si se exige guardar bytes localmente.

La implementación futura debe fijar operaciones permitidas, pruebas de selección/descarga/atribución, caching/retención, límites, costo y derechos de procesamiento, y preservar necesidades documentales. Ninguna recomendación autoriza adquisición o conector durante esta revisión.
