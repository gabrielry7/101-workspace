# Inspección visual de los archivos B2

Fecha de revisión: 2026-10-14, America/Bogota. Codex abrió mediante `view_image` el JPEG original y los WebP de 480×323 y 960×647 generados en esta corrida. Los hashes y las dimensiones realmente decodificadas constan en `technical-inspection.json`.

En ambos derivados se conserva el conjunto de pimientos rojos, hojas y frutos oscuros, con el sujeto reconocible, sin recorte ni texto superpuesto. Se observó la reducción de detalle esperable en 480 px; es adecuada para una figura móvil pequeña y no para ampliar en escritorio. 960 px se reserva a la figura de hasta 640 CSS px del laboratorio a DPR 1. No se acredita calidad para pantallas de alta densidad, hero de ancho completo ni crop alternativo.

No se observaron personas, inmuebles identificables, marcas ni carteles. No se realizó detección automática exhaustiva de terceros. La revisión visual local se ampara en la evaluación limitada del archivo declarado de dominio público; no se entrenó modelo ni se construyó embedding o buscador probabilístico.

La fotografía sólo aporta contexto vegetal/gastronómico genérico. No documenta receta, ingredientes reales, plato, cultivo, proveedor ni sede del fixture. Se conservan el crédito, la etiqueta contextual y el aviso de no respaldo ARS. Los huecos documentales permanecen abiertos.

Resultado de pertinencia/calidad: PASS únicamente para la figura contextual descrita en móvil/escritorio, sujeto a comprobar carga y geometría en navegador. No es aprobación estética del sitio ni suficiencia del paquete del restaurante.
