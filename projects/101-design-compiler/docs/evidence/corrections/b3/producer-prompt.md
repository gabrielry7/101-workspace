# Encargo al productor de esta sesión

Propón cuatro direcciones compositivas coherentes para el mismo escenario ficticio La Mesa. Contexto: BusinessInput/SitePlan/ContentProjection nuevos; cuatro fotografías y clip silencioso B2 con revisión asociada B3; 21 preferencias originales con alcance literal, observaciones de lectura web separadas y captura externa responsive pendiente; gramática compartida contextual V2. No convertir referencias en autorización ni aprobación del resultado.

Salida ArtDirectionV2: principio, feeling definido en decisiones concretas, justificación contextual, referencias con alcance, riesgos, receta de operadores y tokens. Producir diferencias de navegación, dominio título/medio, ritmo, proporciones, colección y reflow móvil, no sólo paletas. La receta usa únicamente operadores/valores certificados del registro local. Sin código arbitrario, assets de referencias, dependencias, edición fotográfica, cambios factuales o funciones operativas. Todas muestran la misma carta, historia, visita y las mismas interfaces demostrativas. Sin reseñas inventadas.

Revisión estética humana pendiente, con opción ninguna. No inferir escala ni belleza de un conteo de combinaciones. Presupuesto: cuatro propuestas de sesión, 24 muestras baratas locales, cuatro finalistas para QA desktop/móvil, máximo dos iteraciones correctivas compartidas antes de entregar un bloqueo preciso; sin llamadas API creativas ni gasto contratado nuevo. Mantener primera evidencia/fallos.

Este texto es el prompt operativo compuesto por el agente a partir de la petición autorizada y los archivos leídos, no una transcripción de una llamada API. El contexto serializado exacto se conserva en context.json. El productor es el modelo activo de la sesión Codex; identidad/version exactas, tokens, latencia total y costo de sesión no están expuestos por la herramienta y quedan null. La hora de grabación y tiempos del sampler no son latencia del LLM. El recorder conserva las propuestas redactadas ahora por el modelo; no es un servicio autónomo de generación conectado.
