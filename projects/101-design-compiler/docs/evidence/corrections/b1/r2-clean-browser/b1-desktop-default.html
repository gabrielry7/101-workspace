Cómo revisarlo

  1. Abre el restaurante y comprueba qué datos respaldan su actividad.
  2. Busca reservas y compara contacto, solicitud, enlace y confirmación.
  3. Abre cada nivel para ver todos los datos faltantes, el responsable y el siguiente paso.
  4. Revisa las sucursales y los casos bloqueados: una incertidumbre no desaparece del objetivo.
