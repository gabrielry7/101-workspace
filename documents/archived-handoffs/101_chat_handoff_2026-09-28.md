# 101 — Chat Handoff / Current State

## What this chat has been about

This chat has been the post-Day-21 repair and reality-validation phase of **UnoCeroUno / 101**.

> **101 does not optimize websites. It learns how a business is discovered, chosen, and purchased from, then changes that system to produce better economic outcomes.**

# 4. Targetability semantics were repaired

Earlier targetability v1 was too coarse and mixed:

```text
fit
reachability
diagnostic completeness
opportunity
truth readiness
```

For example, `NO_EVIDENCED_REACH_CHANNEL` had been used as a reason for `LOW_FIT`, which was semantically wrong.

The repaired audit now separates:

```text
scope
identity
commercial relevance
reachability
diagnostic coverage
truth readiness
concrete observations
priority
```

Missing reachability is no longer treated as low fit.

Examples:

### DOAK’ (#10)

Website Intelligence observed three concrete site issues, but their commercial effect is untested, so no prospect proposal was made.

### Geserprosas (#2)

Still identity unresolved, so no proposal.

### Veterinary directory case (#181)

A vendor email is retained as third-party / directory evidence, not as the veterinary clinic's own contact.

# 18. Important review semantics

Desired semantic model:

```text
PROVIDER ROLE
FOCAL_BUSINESS
EXTERNAL_PROVIDER
REVIEWER
UNKNOWN

EVENT
PERFORMED
CURRENTLY_OFFERED
SCHEDULED
RECOMMENDED
DISCUSSED
DECLINED
REFERRED_ELSEWHERE
HYPOTHETICAL
HISTORICAL
UNKNOWN

STANCE
AFFIRMED
NEGATED
UNCERTAIN

SENTIMENT
POSITIVE
NEGATIVE
NEUTRAL
MIXED
```

This is needed because:

```text
"clinic was very clean"
```

is praise / experience, not cleaning-service evidence.

Whereas:

```text
"I got a dental cleaning here"
```

is offering evidence.

A negative veneer review can still be strong evidence that veneers are performed; service existence and sentiment must not be conflated.

# 19. Category-aware semantic interpretation

Business category should be passed to the semantic interpreter as interpretation context, not supporting evidence.

Example:

```text
business category = dental clinic
review = "limpieza"
```

The category helps decode the language, but the actual sentence still determines whether it means facility cleanliness or dental cleaning.

No production `if dentist:` / `if restaurant:` logic should exist.
